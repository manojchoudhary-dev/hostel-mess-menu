# Hostel Mess Menu

**What is the mess serving today?** A tiny web app with the full weekly menu of my hostel mess at IIIT Bhopal.

**Try it:** open `index.html` in any browser. It opens on today's menu automatically.

## What it does

- All 7 days, all 4 meals — Breakfast, Lunch, Snacks, Dinner
- Day buttons to plan ahead ("what is there on Thursday?")
- The mess's own portion rules at the bottom (the famous one: Gulab Jamun, strictly 1 piece)

## Why I built this

Every hostel student asks the same question three times a day, and the printed menu lives on one notice board. My roommates kept asking me what was on, so I put the menu on a page instead. The data is the real menu the mess shared in November 2026 — including the egg/banana choice at breakfast and the Wednesday/Friday dinner specials.

Plain HTML, CSS and JavaScript in a single file. To reuse it for another hostel, only the `MENU` object in the script needs editing.
